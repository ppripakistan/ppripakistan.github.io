Data Notes & Definitions

A common data language prevents the same number from being used to support incompatible claims.

Population

PPRI's baseline demographic work uses Pakistan Bureau of Statistics Census 2023 material. PBS publishes national, provincial and district tables and detailed results in downloadable formats. Users should always check the census reference period before comparing it with newer estimates.

Administrative geography

District and provincial boundaries can change over time. Every dataset should identify the administrative vintage used. A district comparison is only meaningful when the units are comparable or the transformation is explicitly documented.

Fiscal data

Fiscal indicators should distinguish federal transfers, provincial own-source receipts, grants, expenditure and other categories rather than combining them into a single measure of “wealth.” Definitions should follow the source institution.

Governance indicators

Governance measures require special caution because service outcomes can reflect funding, geography, population density, institutional design and many other factors. PPRI will avoid treating a single indicator as a complete measure of institutional performance.

Reproducibility

  • Store the original source URL.
  • Record publication and reference dates.
  • Preserve downloaded datasets where licensing permits.
  • Document transformations and calculations.
  • Use machine-readable CSV/JSON for derived public datasets.
Current baseline: PBS's 2023 Census provides detailed national, provincial and district demographic tables. See the official Census portal for the latest published tables.
